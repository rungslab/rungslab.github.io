# Rungs — 엔트리로 배우는 AI

**초등학생을 위한 AI 교육 프로젝트 모음. 엔트리(Entry) 블록코딩으로 직접 만들어보며 AI 개념을 배웁니다.**

🔗 **사이트**: https://rungslab.github.io

## 소개

Rungs는 초등학생이 인공지능 개념을 직접 손으로 만들어보며 배울 수 있도록 만든 교육 콘텐츠 플랫폼입니다. 얼굴 인식, 음성 인식, 이미지 분류, 데이터 예측, 텍스트 인식 등 다양한 AI 기술을 엔트리(Entry) 블록코딩으로 구현한 12개 프로젝트를 무료로 제공합니다.

각 프로젝트는 실제 [Machine Learning for Kids](https://machinelearningforkids.co.uk)의 영어 워크시트를 한국 초등 교육 환경(엔트리)에 맞게 변환한 것이며, IT교육학 석사 학위 연구에서 출발했습니다.

## 프로젝트 목록 (12종)

| 카테고리 | 프로젝트 | 난이도 |
|---|---|---|
| 🎤 음성인식 | Secret Code, 소리 지휘자 | 쉬움 / 보통 |
| 😊 얼굴인식 | Laser Eye, Shy Panda(얼굴인식버전), Face Finder | 보통 / 보통 / 쉬움 |
| 📷 이미지인식 | Shy Panda, 가상애완동물, Snap! | 쉬움 / 어려움 / 어려움 |
| 📊 데이터예측 | Journey to School, Catch the Ball, Shoot the Bug | 쉬움 / 어려움 / 어려움 |
| 💬 텍스트인식 | AI 친구 만들기 | 쉬움 |

## 사용 방법

1. [사이트](https://rungslab.github.io)에서 원하는 프로젝트 카드를 클릭
2. 워크시트(PDF)를 다운로드해 단계별 가이드 확인
3. 엔트리 프로젝트 파일(.ent)을 다운로드해 [playentry.org](https://playentry.org)에서 열기
4. 워크시트를 따라 직접 만들어보기

방과후 수업, SW교육 시간, 자유학기제 자료로 바로 활용할 수 있습니다.
